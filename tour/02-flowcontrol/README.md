# Flow Control

Exemplos da seção [Flow control statements: for, if, else, switch and defer](https://go.dev/tour/flowcontrol/1) do Tour. Cada pasta é um programa independente; o número corresponde à página da lição no Tour.

## Como executar

Na raiz do repositório:

```bash
go run ./tour/02-flowcontrol/01-for
go run ./tour/02-flowcontrol/03-while
go run ./tour/02-flowcontrol/05-if
go run ./tour/02-flowcontrol/06-if-declaracao-curta
go run ./tour/02-flowcontrol/07-if-else
go run ./tour/02-flowcontrol/09-switch
go run ./tour/02-flowcontrol/10-switch-ordem-avaliacao
go run ./tour/02-flowcontrol/12-defer
```
